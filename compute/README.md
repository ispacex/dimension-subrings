# compute — exact integral dimension subgroups of small $p$-groups

Computational exploration of Problem 20.84 of the Kourovka notebook
(V. Ionin, R. Mikhailov, T. Petrov, *Dimension subrings of Lie rings*, arXiv:2610.02042):
**is $D_5(G) \subseteq \gamma_4(G)$ for every group $G$**, and can $D_5(G)/\gamma_5(G)$ have
3-torsion? Here $D_n(G) = G \cap (1 + \Delta^n)$, $\Delta$ is the augmentation ideal of
$\mathbb Z[G]$, and $\gamma_n$ is the lower central series ($\gamma_1 = G$).

Results and tables are in [`results/SUMMARY.md`](results/SUMMARY.md) and `results/*.csv`.

## Method

### Coordinates

$\mathbb Z[G] = \mathbb Z\cdot 1 \oplus \Delta$, and $\Delta$ has the basis $\{g - 1 : g \ne 1\}$; an
element of $\Delta$ is the vector of its coefficients at $g \ne 1$ (the coefficient at $1$ is minus
their sum). Hence $g \in D_n(G) \iff$ the unit vector $e_g$ lies in the lattice
$\Delta^n \subseteq \mathbb Z^{|G|-1}$. The lattice $\Delta^n$ has full rank $|G|-1$ (over
$\mathbb Q$ the augmentation ideal of a semisimple algebra is idempotent), so $\Delta/\Delta^n$ is
a finite abelian group.

### Building $\Delta^n$ (method A) and its proof

Let $x_1, \dots, x_d$ generate $G$ (in the code, GAP's `MinimalGeneratingSet`), and let
$b_1, \dots, b_r$ generate $\Delta^{n-1}$ as an abelian group. Then

$$\Delta^n = \operatorname{span}_{\mathbb Z}\{\, b_k (x_i - 1) \,\}.$$

*Proof.* (1) $\Delta = \sum_i \mathbb Z[G](x_i - 1)$ is the left ideal generated by the
$x_i - 1$. Indeed, a finite $G$ is generated by the $x_i$ as a monoid ($x^{-1} = x^{|x|-1}$),
and for a word $g = h x_i$ we have $g - 1 = h(x_i - 1) + (h - 1)$; induction on the length of the
word. (2) $\Delta^{n-1}$ is a two-sided ideal, so $\Delta^{n-1}\mathbb Z[G] = \Delta^{n-1}$.
(3) $\Delta^n = \Delta^{n-1}\Delta$ (a product of additive subgroups is the span of products)
$= \operatorname{span}\{a\, r\, (x_i - 1) : a \in \Delta^{n-1}, r \in \mathbb Z[G]\}
= \operatorname{span}\{a' (x_i - 1) : a' \in \Delta^{n-1}\}$ by (2), and by bilinearity it is
enough to take $a'$ from the generating set $b_k$. $\square$

A remark on the setup: when multiplying by $(x_i - 1)$ **on the right**, no closure is needed —
what is needed is the left ideal generated by the $x_i - 1$, and that is $\Delta$. (The variant
"$\Delta$ as a right ideal, $\Delta^{n-1}(x_i-1)$, then closure under right multiplication by
$G$" is also correct but more expensive; the first version of the code computed it that way, and
the results agreed.) In `--full` mode the code also checks that the resulting lattice is closed
under right multiplication by the generators and by the Pcgs elements — that is, that it really
is an ideal.

### Arithmetic modulo $p^E$ — exact, not approximate

All lattices are taken modulo $D\Delta$, $D = p^E$ ($E = 30, 19, 13$ for $p = 2, 3, 5$:
$D < 2^{31}$, so a product of two residues fits into `int64`). $D\Delta$ is a two-sided ideal,
so the image of $\Delta^n$ in $\Delta/D\Delta$ is generated by the images of the same products,
and the computation modulo $D$ gives exactly $L_n = (\Delta^n + D\Delta)/D\Delta$.

* **Non-membership is always exact.** If $g - 1 \notin \Delta^n + D\Delta$, then
  $g - 1 \notin \Delta^n$, i.e. $g \notin D_n$. Since $\gamma_n \subseteq D_n$ is a theorem,
  the equality $D_n = \gamma_n$ is proved by showing that no $g \notin \gamma_n$ lies in $L_n$.
  No bound on $E$ is needed for this.
* **Membership is exact given a certificate.** If $p^{E-1}\Delta \subseteq \Delta^n + D\Delta$
  (check: $p^{E-1} e_c \in L_n$ for all $c$; function `certified`), then $D\Delta \subseteq \Delta^n$.
  Proof: let the elementary divisors of $\Delta/\Delta^n$ be $p^{a_j}$; then those of
  $\Delta/(\Delta^n + D\Delta)$ are $p^{\min(a_j, E)}$, and exponent of this group $\le p^{E-1}$
  implies $a_j \le E-1$ for all $j$, i.e. $p^{E-1}\Delta \subseteq \Delta^n$. Then $L_n$ is the
  image of $\Delta^n$ itself, and membership modulo $D$ is membership in $\Delta^n$. The
  certificate is always computed in `--full` mode, and in fast mode whenever $D_n \ne \gamma_n$
  (there it is needed for the extra element to be genuine). It passed in every full run.

### Howell form over $\mathbb Z/p^E$

`howell()` brings a system of rows to echelon form: row $i$ starts in column $c_i$ with the entry
$p^{v_i}$, and the columns increase. The step on column $c$: among the remaining rows take one
with the minimal $p$-adic valuation in column $c$, normalize it by a unit, subtract its multiples
from the others (possible: their valuations are not smaller) and **add to the pool the row
$p^{E-v}\cdot(\text{pivot})$** — it vanishes in column $c$.

*Howell property:* every element of the span that is zero in the columns $< c$ lies in the span
of the rows with $c_i \ge c$. Induction on columns: if $x = a\cdot\text{piv} + y$, $y$ from the
new pool (zeros in column $c$) and $x_c = 0$, then $a\,u\,p^{v} \equiv 0 \pmod{p^E}$, i.e.
$p^{E-v} \mid a$, and $a\cdot\text{piv}$ is a multiple of the added row. This gives the
correctness of the membership test `reduce_rows`: column by column the coefficient must be
divisible by $p^{v_i}$, and at the end the remainder must be zero. The order of the lattice is
$|L_n| = \prod p^{E - v_i}$, hence $\log_p[\Delta : \Delta^n + D\Delta]$ in the output
(`index_logp`).

### Fast mode

$D_n \subseteq D_{n-1}$, so at step $n$ only the elements of $D_{n-1}$ are tested; as soon as
$D_n = 1$, all further $D_k = 1 = \gamma_k$ and the computation stops. For a group of class $c$
with $D_k = \gamma_k$ this means that $\Delta^2, \dots, \Delta^{c+1}$ are computed. In fast mode
the index $[\Delta:\Delta^n]$ is printed without a certificate (marked `?` in the CSV) — it is the
index of $\Delta^n + p^E\Delta$.

## Correctness checks (all passed before the enumeration)

1. **$\gamma_n \subseteq D_n$** is checked at every level of every group (an exception otherwise).
2. **$D_1 = G$, $D_2 = \gamma_2$, $D_3 = \gamma_3$** — on all computed groups.
3. **Method B** (`--method B`): $\Delta^n = \operatorname{span}\{(y-1)\,b_k : y \in S\}$, where $S$
   is the union of the conjugacy classes of the **Pcgs** elements (a different generating set),
   multiplication **on the left**, different tables (the left regular action is built by BFS from
   the right one). Proof: $\Delta^n = \Delta\cdot\Delta^{n-1} = \operatorname{span}\{(g-1)c : g \in G,\ c \in \Delta^{n-1}\}$,
   and $(g - 1)c$ lies in $R = \operatorname{span}\{(y-1)c' : y \in S,\ c' \in \Delta^{n-1}\}$ by
   induction on the length of $g$ as a word in $S$: $(gy - 1)c = (gyg^{-1} - 1)(gc) + (g - 1)c$,
   where $gyg^{-1} \in S$ ($S$ is closed under conjugation) and $gc \in \Delta^{n-1}$.
   A and B are compared in full mode: $|D_n|$, the sets of extra elements and the indices
   $[\Delta : \Delta^n]$ for $n \le 6$.
4. **Method C** (`method_c.py`, PARI/GP 2.17, exactly over $\mathbb Z$, no modulus):
   $\Delta^n = $ `mathnf` of $\{b(g - 1) : g \in G\}$ — **all** $g$, no generators, from the full
   multiplication table (a separate export, `export_table.g`); membership is "the HNF does not
   change when the vector is added"; the index is $|\det|$ of the HNF without the row of the
   identity. Agrees with A on $|D_n|$ and on the certified indices.
5. **Known values:** for the cyclic $C_m$, $\Delta^n/\Delta^{n+1} \cong C_m$ (the indices grow by
   $\log_p m$ per step: for $C_{16}$ — $4, 8, 12, 16, 20$); $\Delta/\Delta^2 \cong G_{ab}$;
   for $C_2^4$, $|\Delta^2/\Delta^3| = 2^{10}$.
6. **$D_n = 1$ for large $n$.** For a finite $p$-group this follows from Jennings' theorem
   (without appealing to $\bigcap\Delta^n$): the homomorphism $\mathbb Z[G] \to \mathbb F_p[G]$ maps
   $\Delta^n$ into $\Delta_{\mathbb F_p}^n$, so $D_n(G) \subseteq D_n(G;\mathbb F_p) = M_n(G)$
   (the Jennings series, S. A. Jennings, *The structure of the group ring of a p-group over a
   modular field*, Trans. AMS 50 (1941) 175–185), and $M_n = 1$ for $n$ beyond the length of the
   series ($\mathbb F_p$ is a field, $\Delta_{\mathbb F_p}$ is nilpotent). Every computation went
   on until $D_n = 1$. The statement "$\bigcap_n \Delta^n = 0$ in $\mathbb Z[G]$ for a finite
   $p$-group" is also true (Gruenberg 1957; see I. B. S. Passi, *Group Rings and Their Augmentation
   Ideals*, LNM 715) † — but we do not use it. († — reference from memory, pages not checked.)

## Reduction of the main question to metabelian 2-groups of class 3 (rechecked)

We checked the reduction; one refinement in (c).

**Claim.** $D_5(G) \subseteq \gamma_4(G)$ for all groups $\iff$ $D_5(M) = 1$ for all finite
metabelian 2-groups $M$ of class $\le 3$ (in substance — of class exactly 3).

(a) $G'' = [\gamma_2, \gamma_2] \subseteq \gamma_4$ (since $[\gamma_i, \gamma_j] \subseteq \gamma_{i+j}$),
so $M = G/\gamma_4(G)$ is metabelian of class $\le 3$. $D_n$ is functorial (the image of $D_n(G)$
lies in $D_n(G/N)$), so $D_5(M) = 1 \Rightarrow D_5(G) \subseteq \gamma_4(G)$. Conversely, if
$D_5(M) \ne 1$ with $\gamma_4(M) = 1$, that is a counterexample.
(b) $x - 1$ is a finite combination of products of five factors $g - 1$; all of them lie in
$\mathbb Z[H]$ for a finitely generated $H \ni x$, and $x \in D_5(H)$. $H$ is metabelian of class $\le 3$.
(c) $D_4^2 \subseteq \gamma_4$ (Passi, 1968) and $\gamma_4(H) = 1$, so $x^2 = 1$.
*Refinement:* this has to be applied to $H$ (not to $M$): $x \in D_5(H) \subseteq D_4(H)$, $x^2 \in \gamma_4(H) = 1$.
(d) $H$ is a f. g. nilpotent group; $T$ is its set of elements of odd order (a finite normal
subgroup); $x \notin T$ (order 2). The torsion of $H/T$ is a 2-group, so by Gruenberg (Proc. LMS 7
(1957) 29–62) it is residually a finite 2-group; there is a finite 2-quotient $Q$ in which the
image of $x$ is nontrivial and lies in $D_5(Q)$; $Q$ is metabelian of class $\le 3$. $\square$

**Corollary for finite groups (the order does not grow).** If $G$ is finite, then in (b)–(d)
$H \le M$, $M$ is a finite nilpotent group, $M = P \times T$, and $Q = P$ is the Sylow 2-subgroup
of $M$, i.e. a 2-group of order $\le$ the 2-part of $|G|$. Therefore **checking all metabelian
2-groups of class 3 of order $\le 2^k$ proves $D_5 \subseteq \gamma_4$ for all finite groups whose
2-part has order $\le 2^k$** (in particular, for all groups of order $< 2^{k+1}$).

The same argument for arbitrary $n$: if $D_n = \gamma_n$ for all $n$ holds for all $p$-groups of
order $\le X_p$, then $D_n(G) = \gamma_n(G)$ for all $n$ for every finite $G$ whose $p$-part has
order $\le X_p$ for each $p$ (pass to $G/\gamma_n(G) = \prod_p P_p$; the image of $x \in D_n$ in
each $P_p$ lies in $D_n(P_p) = \gamma_n(P_p) = 1$).

### Sieves used by the enumeration (all are theorems, not heuristics)

* **Class $\le 2$:** $D_n = \gamma_n$ for all $n$, since $D_3 = \gamma_3 = 1$ (and $D_1$, $D_2$
  are classical). Such groups of order 256 are not run through the lattice.
* **Class $\le$ $p$-class.** For the lower exponent-2 central series
  $P_1 = G$, $P_{i+1} = [P_i, G]P_i^2$ we have $\gamma_i \subseteq P_i$, and $p$-class $c$ means
  $P_{c+1} = 1$; hence groups of $p$-class 2 have class $\le 2$. `SmallGroupsInformation(512)`
  lists the ids by rank and $p$-class, and the sieve (`sieve512.sh`) goes over all ranges of
  $p$-class $\ge 3$ — 1 708 439 groups out of 10 494 213. (The first version of the sieve wrongly
  dropped $p$-class 3 as well — an off-by-one in the definition; fixed, and the run was repeated
  in full.)
* **Jennings sieve** (`filter_metab3.g`): for a metabelian group of class 3,
  $D_5 \subseteq D_3 \cap M_5 = \gamma_3 \cap M_5$ and (by (c)) $D_5 \subseteq \Omega_1$ (the
  elements of order $\le 2$; $\gamma_3$ is central, so this is a subgroup). If
  $K = \Omega_1(\gamma_3 \cap M_5) = 1$, then $D_5 = 1$ with no lattices; otherwise the group goes
  to the lattice computation.
* **3-torsion in $D_5/\gamma_5$.** For 3-groups $D_4 = \gamma_4$ ($D_4/\gamma_4$ is a 2-group by
  Passi). As in (a)–(d) with $N = \gamma_5(G)$ (metabelianity is not available here:
  $G''\subseteq\gamma_4$, but not $\gamma_5$), an element of order 3 in $D_5/\gamma_5$ anywhere
  gives a finite 3-group of class $\le 4$ with $D_5 \ne 1$ (for a f. g. nilpotent $H$ kill the
  elements of order prime to 3 and approximate by finite 3-groups by Gruenberg; for a finite $G$
  take the Sylow 3-subgroup of $G/\gamma_5$). For class $\le 3$, $D_5 \subseteq D_4 = \gamma_4 = 1$,
  so only 3-groups of class exactly 4 matter. All 3-groups of order $\le 3^6$ are computed.
* **$p \ge 5$.** $D_4/\gamma_4$ is a 2-group, $D_5/\gamma_5$ has exponent dividing 6 (Tahara), so
  for 5-groups $D_n = \gamma_n$ for $n \le 5$ automatically, and groups of order $5^5$ have class
  $\le 4$ and $D_6 \subseteq D_5 = \gamma_5 = 1$. Order $5^5$ is therefore not computed; $5^4$ is
  computed as a check.

## How to run

The smallest check needs only Python 3 with NumPy: `examples/order16.jsonl` holds the 14 groups
of order 16 exported by `export.g`, and

```bash
python3 dimsub.py A < examples/order16.jsonl          # one JSON line per group: D_n and gamma_n by level
python3 dimsub.py B --full < examples/order16.jsonl   # method B, full mode with certificates
```

The general path:

```bash
# environment (no root, in the home directory):
micromamba create -p ./env -c conda-forge gap-defaults pari python=3.12 numpy python-flint
./run_export.sh 64 1 267 all data/g64.jsonl           # ORDER IDFROM IDTO FILTER OUT
env/bin/python run.py data/g64.jsonl out/A64.jsonl --jobs 8          # fast mode
env/bin/python run.py data/g64.jsonl out/F_A64.jsonl --full --jobs 8 # full mode
env/bin/python run.py data/g64.jsonl out/F_B64.jsonl --full --method B
printf 'ORDER:=64;; IDS:=[1..267];; OUTFILE:="chk/t64.jsonl";;\n' | cat - export_table.g | env/bin/gap -q -b
env/bin/python method_c.py 6 < chk/t64.jsonl > chk/c64.gp && env/bin/gp -q chk/c64.gp > chk/C64.txt
env/bin/python compare.py out/F_A64.jsonl out/F_B64.jsonl chk/C64.txt
./run_sieve.sh 512 11 2044 sieve/c512_11.jsonl sieve/s512_11.json
env/bin/python aggregate.py results/order64.csv out/A64.jsonl
```

Versions: GAP 4.15.1, SmallGroups (smallgrp) 1.5.4, PARI/GP 2.17.3, Python 3.12, NumPy 2.5.4
(python-flint 0.8.0 installed but not needed). Everything from conda-forge via micromamba.
Raw data (`data/`, `out/`, `sieve/`, `chk/`) is not in git — it is reproduced by the commands
above.
