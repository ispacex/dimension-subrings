# Сводка вычислений $D_n(G)$ для малых $p$-групп

Метод, доказательства и проверки — в [`../README.ru.md`](../README.ru.md); здесь только итоги.
Все утверждения точные: решётки $\Delta^n$ считались над $\mathbb Z/p^E$, и это доказуемо
корректно. Непринадлежность по модулю влечёт непринадлежность над $\mathbb Z$, а равенство
$D_n = \gamma_n$ доказывается именно непринадлежностью (см. README).

## Главное

**Контрпримеров нет, нетривиальных $D_n/\gamma_n$ тоже.** Во всех посчитанных группах
$D_n(G) = \gamma_n(G)$ при **всех** $n$: счёт шёл, пока не получалось $D_n = 1$.

| Что | Групп | Итог |
|---|---|---|
| все 2-группы порядка $8, 16, 32, 64, 128$ | 5 + 14 + 51 + 267 + 2328 = 2665 | $D_n = \gamma_n$ при всех $n$ |
| все группы порядка $2^8 = 256$ класса $\ge 3$ (при классе $\le 2$ всё тривиально) | 24 328 из 56 092 | $D_n = \gamma_n$ при всех $n$ |
| все метабелевы группы порядка $2^9 = 512$ класса 3 | 1 587 389 (сито по 1 708 439 группам $p$-класса $\ge 3$) | $D_5 = 1$; у 2792 групп, прошедших сито, решётка даёт $D_4 = D_5 = 1$ |
| все 2-группы порядка $2^{10} = 1024$ класса 3 (прогон $2^{10}$, через ANUPQ и лемму о минимальном контрпримере, [`../pq1024/README.ru.md`](../pq1024/README.ru.md)) | 88 809 потомков шага 1 класса 3, из них 3400 кандидатов | $D_5 = 1$; у всех 3400 кандидатов $D_4 = D_5 = 1$ и $D_n = \gamma_n$ |

| все группы порядка $5^4 = 625$ | 15 | $D_n = \gamma_n$ (контроль; для $p \ge 5$ и $n \le 5$ это теорема) |

### Следствия для произвольных конечных групп (через сведение из README)

1. **$D_5(G) \subseteq \gamma_4(G)$ для всякой конечной группы $G$, у которой 2-часть порядка
   не больше $2^{10}$.** В частности, это верно для всех групп порядка $< 2048$. Достаточно
   проверить метабелевы 2-группы класса 3 порядка $\le 2^{10}$, и все они проверены: до 256 —
   полностью решёткой, порядок 512 — ситом Дженнингса и затем решёткой, порядок 1024 —
   перебором по лемме о минимальном контрпримере и решёткой (прогон $2^{10}$).
2. **$D_n(G) = \gamma_n(G)$ при всех $n$ для всякой конечной группы порядка $< 512$.**
   Действительно, у таких групп 2-часть $\le 2^8$, 3-часть $\le 3^5$, а $p$-часть при
   $p \ge 5$ не больше $p^3$ (у таких $p$-групп класс $\le 2$). Все соответствующие
   $p$-группы проверены.
3. **$D_5/\gamma_5$ не имеет 3-кручения ни у какой конечной группы, у которой 3-часть порядка
   $\le 3^6$.**

## Что видно в данных

* У каждой группы класса $c$ получилось $D_{c+1} = 1$, причём $D_k = \gamma_k$ на каждом шаге.
  Порядок 256 даёт классы 3..7 (21 325 / 2642 / 320 / 38 / 3 групп), порядок 729 — классы 1..5.
* Для метабелевых групп класса 3 сито Дженнингса $K = \Omega_1(\gamma_3 \cap M_5)$
  отсекает почти всё:

  | Порядок | Отсечено ситом |
  |---|---|
  | 64 | 111 из 114 |
  | 128 | 1116 из 1137 |
  | 256 | 21 105 из 21 325 |
  | 512 | 1 584 597 из 1 587 389 |

  У оставшихся решётка дала даже $D_4 = 1$, так что до $D_5$ дело не доходит.
  Подробно — в `sieve_stats.csv`.
* Для 3-групп класса 4 аналогичное сито $K = \Omega_1(\gamma_4 \cap M_5)$ отсекает мало: у 729 —
  9 групп из 71, у 2187 — 107 из 1309.
* Все группы класса 3 порядков 64–512 оказались метабелевыми.

## Проверки (подробнее — в README, раздел «Проверки корректности»)

* $\gamma_n \subseteq D_n$ проверено на каждом уровне каждой группы; $D_1 = G$, $D_2 = \gamma_2$,
  $D_3 = \gamma_3$ — везде.
* Метод B (классы сопряжённости элементов Pcgs, умножение слева) против метода A в полном
  режиме на порядках 8, 16, 32, 64, 81, 243, 625: **0 расхождений**. Сравнивались $|D_n|$,
  лишние элементы и индексы $[\Delta : \Delta^n]$ при $n \le 6$.
* Метод C (PARI/GP, HNF над $\mathbb Z$ от всех $b(g-1)$, без модуля): все группы порядков
  8, 16, 32, 64, 81 и 12 групп порядка 128 (классы 5–6 и группы, прошедшие сито).
  **0 расхождений** по $|D_n|$ и точным индексам.
* Полный режим (все 2-группы порядка $\le 128$, 3-группы $\le 243$, 625): сертификат точности
  $p^E\Delta \subseteq \Delta^n$ прошёл на всех ~18 000 уровнях. Проверка «$\Delta^n$ — правый
  идеал» тоже прошла везде.
* Первая версия метода A (с замыканием по умножению справа) и окончательная (без замыкания)
  совпали на всех 267 группах порядка 64 и на 39 группах порядка 729.

## Порядок $2^{10}$ — закрыт

Метод, доказательство леммы и проверки — в [`../pq1024/README.ru.md`](../pq1024/README.ru.md). Из перебора порядка 512
следует лемма: контрпример порядка $2^{10}$ имеет циклический центр и
$D_5 = \Omega_1(Z) \subseteq \gamma_3 \cap M_5$, а сам он — потомок шага 1 библиотечной группы
порядка 512 с $p$-классом $\ge 3$, классом 2 или 3 и циклической $\gamma_3$. Генератор сверен
со SmallGroups на порядках 64–512. Прогон закончен 15.10.2026 в 19:55 UTC, все 858 кусков.

## Что считать дальше

1. **Порядок $2^{11}$ (перебор $2^{11}$, [`../pq2048/README.ru.md`](../pq2048/README.ru.md)).** Порядок $2^{10}$ закрыт (выше). Для $2^{11}$ тот же путь
   требует родителей порядка 1024 класса $\le 3$ с циклической $\gamma_3$; по оценке перебора через $p$-накрытие их
   $0{,}5$–$1{,}1 \cdot 10^9$, так что нужен отсев целых поддеревьев или другая постановка.
2. **Полный перебор 3-групп порядка 2187 класса 4:** 1202 кандидата по ~5 мин, то есть около
   100 процессорных часов в нынешней реализации на numpy. Сначала стоит перенести `howell`
   на C/flint.
3. **Факторы известных контрпримеров** (Рипс, $D_4 \ne \gamma_4$, порядок $2^{38}$;
   Бартольди–Михайлов, $3^{494}$) по большим нормальным подгруппам. Цель — найти наименьший
   порядок, на котором $D_4 \ne \gamma_4$ уже виден, чтобы откалибровать, насколько далеко
   до возможного контрпримера к $D_5 \subseteq \gamma_4$.
