# Сводка вычислений $D_n(G)$ для малых $p$-групп

Метод, доказательства и проверки — в [`../README.ru.md`](../README.ru.md); здесь только итоги.
Все утверждения точные: решётки $\Delta^n$ считались над $\mathbb Z/p^E$, и это доказуемо
корректно. Непринадлежность по модулю влечёт непринадлежность над $\mathbb Z$, а равенство
$D_n = \gamma_n$ доказывается именно непринадлежностью (см. README).

## Главное

**Контрпримеров нет, нетривиальных $D_n/\gamma_n$ тоже.** Во всех посчитанных группах
$D_n(G) = \gamma_n(G)$ при **всех** $n$: счёт шёл, пока не получалось $D_n = 1$.

### Следствия для произвольных конечных групп (через сведение из README)

1. **$D_5(G) \subseteq \gamma_4(G)$ для всякой конечной группы $G$, у которой 2-часть порядка
   не больше $2^{10}$.** В частности, это верно для всех групп порядка $< 2048$. Достаточно
   проверить метабелевы 2-группы класса 3 порядка $\le 2^{10}$, и все они проверены: до 256 —
   полностью решёткой, порядок 512 — ситом Дженнингса и затем решёткой, порядок 1024 —
   перебором по лемме о минимальном контрпримере и решёткой (прогон $2^{10}$).
2. **$D_n(G) = \gamma_n(G)$ при всех $n$ для всякой конечной группы порядка $< 512$.**
   Действительно, у таких групп 2-часть $\le 2^8$, 3-часть $\le 3^5$, а $p$-часть при
   $p \ge 5$ не больше $p^3$ (у таких $p$-групп класс $\le 2$). Все соответствующие
   $p$-группы проверены.
3. **$D_5/\gamma_5$ не имеет 3-кручения ни у какой конечной группы, у которой 3-часть порядка
   $\le 3^6$.**
4. **$D_n/\gamma_n$ не имеет 3-кручения ни при каком $n$ ни у какой конечной группы, 3-часть порядка которой $\le 3^9$**; иначе говоря, 3-группа с 3-кручением в каком-либо $D_n/\gamma_n$ имеет порядок $\ge 3^{10}$
   ([MATH-403](https://default.kaiku.tech/issue/MATH-403)). У примера наименьшего порядка $Q$ $\gamma_n(Q) = 1$, центр
   цикличен, а цоколь лежит в $D_{c+1}(Q) \cap Q'' \cap M_{c+1}$ ($c$ — ступень; для $Q''$ — Гупта 1991);
   ступень $\le 3$ невозможна ($D_4 = \gamma_4$ в 3-группах), при ступени 4 $D_n \subseteq D_5 = \gamma_5 = 1$ (до $3^9$, статья),
   а ступень $\ge 5$ исключена до $3^9$ двумя прогонами из таблицы.

## Что видно в данных

* У каждой группы класса $c$ получилось $D_{c+1} = 1$, причём $D_k = \gamma_k$ на каждом шаге.
  Порядок 256 даёт классы 3..7 (21 325 / 2642 / 320 / 38 / 3 групп), порядок 729 — классы 1..5.
* Для метабелевых групп класса 3 сито Дженнингса $K = \Omega_1(\gamma_3 \cap M_5)$
  отсекает почти всё:

  | Порядок | Отсечено ситом |
  |---|---|
  | 64 | 111 из 114 |
  | 128 | 1116 из 1137 |
  | 256 | 21 105 из 21 325 |
  | 512 | 1 584 597 из 1 587 389 |

  У оставшихся решётка дала даже $D_4 = 1$, так что до $D_5$ дело не доходит.
  Подробно — в `sieve_stats.csv`.
* Для 3-групп класса 4 аналогичное сито $K = \Omega_1(\gamma_4 \cap M_5)$ отсекает мало: у 729 —
  9 групп из 71, у 2187 — 107 из 1309.
* Все группы класса 3 порядков 64–512 оказались метабелевыми.

## Проверки (подробнее — в README, раздел «Проверки корректности»)

* $\gamma_n \subseteq D_n$ проверено на каждом уровне каждой группы; $D_1 = G$, $D_2 = \gamma_2$,
  $D_3 = \gamma_3$ — везде.
* Метод B (классы сопряжённости элементов Pcgs, умножение слева) против метода A в полном
  режиме на порядках 8, 16, 32, 64, 81, 243, 625: **0 расхождений**. Сравнивались $|D_n|$,
  лишние элементы и индексы $[\Delta : \Delta^n]$ при $n \le 6$.
* Метод C (PARI/GP, HNF над $\mathbb Z$ от всех $b(g-1)$, без модуля): все группы порядков
  8, 16, 32, 64, 81 и 12 групп порядка 128 (классы 5–6 и группы, прошедшие сито).
  **0 расхождений** по $|D_n|$ и точным индексам.
* Полный режим (все 2-группы порядка $\le 128$, 3-группы $\le 243$, 625): сертификат точности
  $p^E\Delta \subseteq \Delta^n$ прошёл на всех ~18 000 уровнях. Проверка «$\Delta^n$ — правый
  идеал» тоже прошла везде.
* Первая версия метода A (с замыканием по умножению справа) и окончательная (без замыкания)
  совпали на всех 267 группах порядка 64 и на 39 группах порядка 729.

## Что считать дальше

1. **Порядок $2^{11}$ (перебор $2^{11}$, [`../pq2048/README.ru.md`](../pq2048/README.ru.md)).** Порядок $2^{10}$ закрыт (выше). Для $2^{11}$ тот же путь
   требует родителей порядка 1024 класса $\le 3$ с циклической $\gamma_3$; по оценке перебора через $p$-накрытие их
   $0{,}5$–$1{,}1 \cdot 10^9$, так что нужен отсев целых поддеревьев или другая постановка.
2. **Полный перебор 3-групп порядка 2187 класса 4 — сделан** (не numpy-кодом этого каталога,
   который считал только выборку из 49 групп): все 1202 кандидата вариантами A на C (4905 с) и
   B (157 с, три потока) из cflint-core, везде $D_n = \gamma_n$ при всех $n$ (строка выше). Для
   $D_5$ он уже был не нужен: группы метабелевы, и работает Гупта–Тахара 1985.
3. **Факторы известных контрпримеров** (Рипс, $D_4 \ne \gamma_4$, порядок $2^{38}$;
   Бартольди–Михайлов, $D_7 \ne \gamma_7$, $3^{494}$) по большим нормальным подгруппам. Цель — найти наименьший
   порядок, на котором $D_4 \ne \gamma_4$ уже виден, чтобы откалибровать, насколько далеко
   до возможного контрпримера к $D_5 \subseteq \gamma_4$.
   **Рипс: подгруппы разобраны, факторы — выборочно ([MATH-39](https://default.kaiku.tech/issue/MATH-39),
   [`../magnus/README.md`](../magnus/README.md), `tah.g` … `tahfam.g`).** Группа Рипса взята по
   копредставлению Тахары (1978, §3, $k=2$, $\ell=0$). У неё $D_4 = \{1, w\}$, $w = y_1^{128}$
   (с сертификатом), и $\Omega_1(Z) = \langle w\rangle$. Все 15 максимальных подгрупп и $G/\langle w\rangle$
   имеют $D_4 = 1$. Значит, $D_4 = 1$ у всякой собственной подгруппы, и всякий собственный фактор
   пропускается через $G/\langle w\rangle$. Случайные спуски по 26 147 факторам (с повторениями) новых
   $D_4 \ne 1$ не нашли. Подъём по показателям шаблона Тахары не нашёл ничего ниже $2^{38}$. Так
   что проверенные секции группы Рипса калибровки ниже $2^{38}$ не дают: среди известных нам
   примеров группа Рипса по-прежнему наименьшая с $D_4 \ne \gamma_4$. Что $D_4 = 1$ у всех
   собственных факторов, проверено только на выборке, а секции $H/N$ с $H < G$, $N \ne 1$ не
   проверялись.
   **Нижняя оценка ([MATH-415](https://default.kaiku.tech/issue/MATH-415)):** 2-группа с
   $D_4 \ne \gamma_4$ имеет порядок $\ge 2^{11}$. Порядок $2^9$ — решетом по SmallGroups
   ([`../magnus/README.md`](../magnus/README.md), `d4s9.g`, 4421 кандидат), порядок $2^{10}$ — по
   непосредственным потомкам шага 1 всех 10 208 630 возможных родителей порядка 512 (ступень 2–3, 2-ступень $\ge 2$, циклическая $\gamma_3$), где
   $n \in D_4$ стало линейным условием на $p$-накрытии ([`../pq1024/README.md`](../pq1024/README.md),
   `run_d4lin.sh`, tm `d4lin-full`, 25 ч). Значит, $D_4(G) = \gamma_4(G)$ для всякой конечной $G$,
   силовская 2-подгруппа которой имеет порядок $\le 2^{10}$.
   Бартольди–Михайлов ([MATH-403](https://default.kaiku.tech/issue/MATH-403), [`../magnus/bm494/`](../magnus/bm494/README.md)):
   их 3-группа — пример $D_7 \ne \gamma_7$, а не $D_4 \ne \gamma_4$. Её класс 6, так что
   $\gamma_7 = 1$, свидетель $w$ имеет порядок 3. Центр — $C_3 \times C_{3^{15}}$, и $w$ лежит в его
   подгруппе Фраттини, так что ни одна подгруппа индекса 3 в центре не избегает $w$; это согласуется
   с тем, что их спуск (по максимальным подгруппам центра, не содержащим $w$) остановился на $3^{494}$.
   Центральная подгруппа $\langle u\rangle$ порядка 3 с $u \notin \langle w\rangle$ (таких 3) всё же
   даёт $G/\langle u\rangle$ порядка $3^{493}$ с $w \ne 1$, то есть $D_7 \ne \gamma_7$. Его центр
   цикличен, так что ни один собственный фактор $w$ не сохраняет; эти три фактора покрывают все
   факторы $G$, сохраняющие $w$. Подгруппы и новые свидетели в факторах не проверялись. Что
   $w \in D_7$ — рассуждение BM (предложение 9.2; группа (9.2) отображается в $G$, $\omega \mapsto w$), а не наше вычисление.
