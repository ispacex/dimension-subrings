# pq2048 — к порядку $2^{11}$: отсев целых поддеревьев

English version: [README.md](README.md).

Постановка: отсекать вершину $R$ дерева порождения
2-групп можно только по условию, которое (а) необходимо для родителя минимального
контрпримера $Q$ по лемме из [`../pq1024/README.md`](../pq1024/README.md) или для любой его
факторгруппы-предка и (б) переходит на факторгруппы, так что под отсечённой вершиной
кандидатов нет. Условие должно быть доказано; проверенное только на данных не годится.

Здесь: доказанные условия (теоремы 1 и 2), их проверка на порядках 32–512, сколько они
отсекают, оценка для $2^{11}$ и вывод о постановке. **Итог коротко.**

* Доказаны два условия, которые переходят на факторгруппы: ранговое (Г) и «бюджет порядка»
  (Г$_N$) для поиска кандидатов порядка $2^N$. Оба держатся на одной лемме: для группы класса 3 с
  циклическим центром коммутатор задаёт невырожденное спаривание
  $\gamma_2/(\gamma_2 \cap Z) \times Q/C_Q(\gamma_2) \to \gamma_3$.
* Ничего не потеряно: перебор с отсевом даёт тех же кандидатов, 3 / 11 / 64 / 308 на порядках
  64–512, по рангам и построчно; теоремы проверены на всех предках всех этих кандидатов.
* (Г) на порядках до $2^{10}$ не отсекает ничего (и это видно из неравенств). (Г$_N$) отсекает
  сильно, но в основном самих родителей: на порядке 512 их остаётся ≈ 4 %, а родителей порядка
  $2^{10}$ для $2^{11}$ — по выборке $10^5$–$2 \cdot 10^6$ вместо $0{,}5$–$1{,}1 \cdot 10^9$.
* Остаётся дорогим порождение: раскрыть ≈ 9 млн вершин порядка 512 (в основном $p$-класса 2
  рангов 5 и 6) — ≈ 100 CPU-суток по выборке (раздел «Оценка для $2^{11}$»), из них ≈ 85 % на ранг 5 (ранг 6 там
  занижен: без правил шагов (`steps.g`) он стоил бы ≈ 240 суток, с ними — около суток). Предложение — закрыть $2^{11}$ для
  рангов $\ne 5$ (≈ 2–3 CPU-суток с правилами шагов, ранги 2–4 — сутки), а ранг 5 — после доказательства
  утверждения 1 из «Не доказано» (раздел «Вывод»). Ранги 2 и 3 уже прогнаны: 603 кандидата
  порядка $2^{11}$, у всех $D_4 = D_5 = 1$.

## Обозначения

*Кандидат* — конечная 2-группа $Q$ класса 3 с условиями (1)–(4) леммы: центр $Z(Q)$
циклический, его инволюция $n$ лежит в $\gamma_3(Q) \cap M_5(Q)$, $2$-класс $c \ge 4$,
$P_c(Q) = \langle n \rangle$, родитель $R = Q/P_c(Q)$. Здесь $P_1 = Q$,
$P_{i+1} = [P_i, Q] P_i^2$ (`PCentralSeries(Q, 2)`), $P_c \ne 1 = P_{c+1}$. Предки $R$ в
дереве — это $Q/P_k(Q)$, $2 \le k \le c$; все они — факторгруппы $Q$ по подгруппам из
$\Phi(Q) = P_2(Q)$, и у всех ранг $d = d(Q)$.

Ниже используются только: класс 3, $Z(Q)$ циклический, $n \in \gamma_3(Q)$. Условие
$n \in M_5$ в теоремах не участвует (оно не переходит на факторгруппы: это условие «снизу»).

$d = d(Q)$, $r_{\max}(d) = \min(d, d(d-1)/2)$, $Q_{ab} = Q/\gamma_2(Q)$. Для конечной абелевой
2-группы $H \cong \bigoplus_j \mathbb Z/2^{\lambda_j}$, $\lambda_1 \ge \lambda_2 \ge \dots$, *тип* —
это $(\lambda_j)$, ранг $\mathrm{rk}\,H$ — число слагаемых. *Объединение* типов
$H_1 \vee H_2$ — группа с $\lambda_j = \max(\lambda_j(H_1), \lambda_j(H_2))$.

## Лемма о спаривании

**Лемма A.** Пусть $Q$ — 2-группа класса 3 с циклическим центром (в доказательстве нужна
только цикличность $\gamma_3(Q)$),
$C = C_Q(\gamma_2(Q))$, $X = \gamma_2(Q)/(\gamma_2(Q) \cap Z(Q))$. Тогда
$X \cong Q/C$, $Q/C$ — факторгруппа $Q_{ab}$, и $\mathrm{rk}\,X \le r_{\max}(d)$.

*Доказательство.* Класс 3: $[\gamma_2, \gamma_2] \le \gamma_4 = 1$, так что $\gamma_2$ абелева и
$\gamma_2 \le C$; $\gamma_3 \le Z(Q)$, и $\gamma_3$ циклическая как подгруппа циклической
$Z(Q)$, $|\gamma_3| = 2^e$. Для $y \in \gamma_2$, $x \in Q$ коммутатор $[y, x]$ лежит в
центральной $\gamma_3$, поэтому
$[yy', x] = [y, x]^{y'}[y', x] = [y,x][y',x]$ и $[y, xx'] = [y, x'][y, x]^{x'} = [y,x][y,x']$:
отображение $(y, x) \mapsto [y, x]$ билинейно $\gamma_2 \times Q \to \gamma_3$. Левое ядро —
$\gamma_2 \cap Z(Q)$, правое — $C$, так что получается невырожденное спаривание
$X \times Q/C \to \gamma_3 \cong \mathbb Z/2^e$. Отсюда $X \hookrightarrow \mathrm{Hom}(Q/C, \mathbb Z/2^e)$
и $Q/C \hookrightarrow \mathrm{Hom}(X, \mathbb Z/2^e)$; для конечной абелевой $B$
$|\mathrm{Hom}(B, \mathbb Z/2^e)| \le |B|$ с равенством только при $\exp B \mid 2^e$, и тогда
$\mathrm{Hom}(B, \mathbb Z/2^e) \cong B$. Значит, $|X| = |Q/C|$ и $X \cong Q/C$. Так как
$\gamma_2 \le C$, $Q/C$ — факторгруппа $Q_{ab}$ и порождена $d$ элементами. С другой стороны,
$\gamma_2 = \langle [x_i, x_j] \rangle \gamma_3$ для порождающих $x_1, \dots, x_d$ (коммутатор
билинеен по модулю $\gamma_3$), а $\gamma_3 \le \gamma_2 \cap Z$; поэтому $X$ порождена
$d(d-1)/2$ элементами. $\square$

**Лемма B (типы).** Если конечная абелева 2-группа $H$ отображается на $H_1$ и на $H_2$, то
$\lambda_j(H) \ge \max(\lambda_j(H_1), \lambda_j(H_2))$ при всех $j$, и
$|H| \ge |H_1 \vee H_2|$.

*Доказательство.* Из $H \twoheadrightarrow H_i$ следует $2^t H \twoheadrightarrow 2^t H_i$, и
ранг не растёт при переходе к факторгруппе: $\#\{j : \lambda_j(H) > t\} = \mathrm{rk}\,2^tH \ge
\mathrm{rk}\,2^tH_i = \#\{j : \lambda_j(H_i) > t\}$ при всех $t \ge 0$. Это и есть
покомпонентное неравенство упорядоченных $\lambda$. $\square$

## Теорема 1: условие (Г)

**Условие (Г)** для 2-группы $V$ класса $\le 3$ ранга $d$: существует циклическая подгруппа
$K$ с $\gamma_3(V) \le K \le \gamma_2(V) \cap Z(V)$ и $\mathrm{rk}(\gamma_2(V)/K) \le r_{\max}(d)$.

**Теорема 1.** Если $Q$ — кандидат и $N \trianglelefteq Q$, $N \le \Phi(Q)$, то $V = Q/N$
удовлетворяет (Г). В частности, (Г) выполнено для $R$, для всех его предков в дереве и для
самого $Q$.

*Доказательство.* $d(V) = d(Q)$, так как $N \le \Phi(Q)$. Возьмём $K = (\gamma_2(Q) \cap Z(Q))N/N$.
Она циклическая (образ подгруппы циклической $Z(Q)$), центральная, лежит в
$\gamma_2(V) = \gamma_2(Q)N/N$ и содержит $\gamma_3(V) = \gamma_3(Q)N/N$, так как
$\gamma_3(Q) \le \gamma_2(Q) \cap Z(Q)$. Наконец, $\gamma_2(V)/K$ — факторгруппа $X$, и
$\mathrm{rk}(\gamma_2(V)/K) \le \mathrm{rk}\,X \le r_{\max}(d)$ по лемме A. $\square$

*Следствия* (проверяются без перебора $K$): (Г3) $\mathrm{rk}\,\gamma_2(V) \le r_{\max} + 1$;
(Г4) $\mathrm{rk}(\gamma_2(V)/(\gamma_2(V) \cap Z(V))) \le r_{\max}$.

*Переход на факторгруппы* (свойство (б)): если $V$ удовлетворяет (Г) с подгруппой $K$ и
$M \le \Phi(V)$, то $V/M$ удовлетворяет (Г) с подгруппой $KM/M$ (те же рассуждения: образы
циклических и центральных подгрупп, ранг факторгруппы не больше). Поэтому множество вершин с (Г)
замкнуто вверх по дереву, и отсечение по (Г) ничего не теряет.

## Теорема 2: условие (Г$_N$), бюджет порядка

**Лемма C.** Пусть $Q$ — 2-группа класса 3 с циклической $\gamma_3(Q)$ порядка $2^e \ge 2$. Тогда
у $Q_{ab}$ хотя бы два инварианта не меньше $e$ ($\lambda_2(Q_{ab}) \ge e$), а $X$ (лемма A, если
центр циклический) содержит элемент порядка $\ge 2^e$.

*Доказательство.* $\gamma_3 = [\gamma_2, Q]$ порождена коммутаторами $[[u,v],w]$ (отображение
$g \mapsto [g, w]$ — гомоморфизм на $\gamma_2$, см. лемму A). Циклическая 2-группа, порождённая
множеством, порождается одним его элементом (подгруппы образуют цепь), так что
$\gamma_3 = \langle [x,y,z] \rangle$. При фиксированном $z$ отображение $(u, v) \mapsto [u, v, z]$
корректно определено на $Q_{ab} \times Q_{ab}$, билинейно и знакопеременно (класс 3:
$[ug, v] = [u,v][u,v,g][g,v]$, $[u,v,g] \in \gamma_4 = 1$, $[g,v] \in \gamma_3$ центральна).
Значит, оно пропускается через $\Lambda^2 Q_{ab} \cong \bigoplus_{i<j} \mathbb Z/2^{\min(\lambda_i,\lambda_j)}$,
экспонента которой $2^{\lambda_2}$; а в образе есть элемент порядка $2^e$. Элемент
$[x,y](\gamma_2 \cap Z) \in X$ спаривается с $zC$ в образующую $\gamma_3$, поэтому его порядок
не меньше $2^e$. $\square$

**Условие (Г$_N$)** для $V$ ранга $d$, $2^{e_V} = |\gamma_3(V)|$: существует $K$ из условия (Г), для
которой
$$2\,|K|\,\bigl|A \vee B \vee E_1\bigr|\,\bigl|A \vee V_{ab} \vee E_2\bigr| \le 2^N,$$
где $A = \gamma_2(V)/K$, $B = V/C_V(\gamma_2(V))$, $E_1 = \mathbb Z/2^{e_V+1}$, $E_2 = E_1^2$.

**Теорема 2.** Если $Q$ — кандидат порядка $2^N$ и $N_0 \trianglelefteq Q$, $n \in N_0 \le \Phi(Q)$
(например, $N_0 = P_k(Q)$, $2 \le k \le c$: все предки $R$ и сам $R$), то $V = Q/N_0$
удовлетворяет (Г$_N$).

*Доказательство.* Пусть $K$ — та же, что в теореме 1, $X$ и $C$ — из леммы A, $2^e = |\gamma_3(Q)|$.
Так как $n \in \gamma_3(Q) \cap N_0$, $|\gamma_3(Q)| \ge 2|\gamma_3(V)|$, то есть $e \ge e_V + 1$.
Далее $|Q| = |Q_{ab}|\,|\gamma_2(Q)|$ и $|\gamma_2(Q)| = |X|\,|\gamma_2(Q) \cap Z(Q)|$.

* $X \twoheadrightarrow A$ (по определению $K$); $X \cong Q/C \twoheadrightarrow V/(CN_0/N_0)
  \twoheadrightarrow B$, так как образ $C$ централизует $\gamma_2(V)$; $X \twoheadrightarrow E_1$
  по лемме C. По лемме B $|X| \ge |A \vee B \vee E_1|$.
* $|\gamma_2(Q) \cap Z(Q)| = |K| \cdot |\gamma_2(Q) \cap Z(Q) \cap N_0| \ge 2|K|$, так как
  $n \in \gamma_3(Q) \le \gamma_2(Q) \cap Z(Q)$ и $n \in N_0$.
* $Q_{ab} \twoheadrightarrow Q/C \cong X \twoheadrightarrow A$, $Q_{ab} \twoheadrightarrow V_{ab}$ и
  $Q_{ab} \twoheadrightarrow E_2$ (лемма C, $\lambda_1 \ge \lambda_2 \ge e \ge e_V + 1$). По лемме B
  $|Q_{ab}| \ge |A \vee V_{ab} \vee E_2|$.

Перемножая, $2^N = |Q| \ge 2|K|\,|A \vee B \vee E_1|\,|A \vee V_{ab} \vee E_2|$. $\square$

*Переход на факторгруппы:* при $V \to V/M$, $M \le \Phi(V)$, подгруппа $K$ переходит в $KM/M$
(не больше), $A$, $B$ и $V_{ab}$ — в свои факторгруппы ($C_{V/M}(\gamma_2(V/M))$ содержит образ
$C_V(\gamma_2(V))$), $e_V$ не растёт, и левая часть не растёт. Условие зависит от целевого
порядка $2^N$: при поиске кандидатов порядка $\le 2^N$ оно ничего не теряет (с большим $N$ оно
только слабее).

*Для самого родителя* ($V = R$, $|R| = 2^{N-1}$) неравенство точное: $Q_{ab} = R_{ab}$ (так как
$n \in \gamma_2(Q)$), и (Г$_N$) требует, в частности, $\lambda_2(R_{ab}) \ge e_R + 1$: у родителя
класса 3 абелианизация должна иметь два инварианта больше $|\gamma_3(R)|$. На предках порядка
$2^{N-1-s}$ запас в $2^s$ раз больше.

Вместе с (Г) это все условия, которые проверяет `prune.g` (`PR_Data`: поля `p3`, `p4`, `p5` =
(Г), `p5b` = (Г$_N$)). Цикличность $\gamma_3$ входит в (Г) (нужна циклическая $K \ge \gamma_3$),
класс $\le 3$ проверяется отдельно.

## Следствие: что остаётся при $2^{11}$

Подставим в (Г$_N$) грубые оценки $|K| \ge 2^{e_V}$ ($K \ge \gamma_3(V)$),
$|A \vee B \vee E_1| \ge 2^{e_V+1}$, $|A \vee V_{ab} \vee E_2| \ge 2^{d-2} \cdot 2^{2(e_V+1)}$
(у $V_{ab}$ $d$ инвариантов, два из них заменены на $\ge e_V + 1$):

**Следствие 1.** Если $Q$ — кандидат порядка $2^N$, то у всякого его предка $V$ (и у $R$)
класса 3 выполнено $d + 4e_V + 2 \le N$, где $2^{e_V} = |\gamma_3(V)|$. При $N = 11$: у предков
класса 3 $|\gamma_3(V)| = 2$ и $d \le 5$. В частности, при $d \ge 6$ все предки кандидата порядка
$2^{11}$, включая $R$, имеют класс $\le 2$, а при $d \le 5$ родитель класса 3 имеет
$|\gamma_3(R)| = 2$, то есть $|\gamma_3(Q)| = 4$. $\square$

Где не работает (Г):

* **При $d = 2, 3$ условие (Г) пусто.** $\gamma_2(V) = \langle [x_i,x_j] \rangle \gamma_3(V)$, поэтому
  при $K = \gamma_3(V)$ ранг $\gamma_2(V)/K$ не больше $d(d-1)/2$; при $d = 2$ это $1 = r_{\max}$,
  при $d = 3$ это $3 = r_{\max}$. Остаётся только цикличность $\gamma_3$.
* **При $d \ge 4$ (Г) включается поздно.** Чтобы (Г) нарушилось, нужно
  $\mathrm{rk}\,\gamma_2(V) \ge r_{\max} + 1 = d + 1$, то есть
  $|V| \ge |V_{ab}|\,|\gamma_2(V)| \ge 2^{2d+1}$: при $d = 4$ это порядок $\ge 2^9$, при $d = 5$ —
  $\ge 2^{11}$. Для поиска $2^{11}$ (вершины до $2^{10}$) (Г) может отсечь только вершины ранга 4
  порядков $2^9$ и $2^{10}$; на порядках 32–512 оно не отсекло ни одной.

Работает бюджет (Г$_N$): у предков он отсекает вершины с большой $\gamma_2$ или нетривиальной
$\gamma_3$ при большом ранге (следствие 1), а у самого родителя он точный.

## Вершины без потомков

`PqDescendants` сначала строит $\mathrm{Aut}(V)$ и только потом узнаёт, что потомков нет или
что все они будут отброшены. `steps.g` (`TS_Steps`) решает это заранее по $p$-накрытию вершины
(один вызов `PqPCover`, без $\mathrm{Aut}$) и оставляет `tree.g` только те шаги, на которых могут
быть нужные потомки.

**Обозначения.** $V$ — вершина $2$-класса $c$, ранга $d$, $|\gamma_3(V)| = 2^{e_V}$;
$V = F/K$, $F$ свободна ранга $d$; $V^* = F/[K,F]K^2$ (`PqPCover`); мультипликатор
$M = K/[K,F]K^2$ — последние $m$ элементов pcgs $V^*$; ядро $N = P_{c+1}(V^*) \le M$
(`PCentralSeries(V^*, 2)[c+1]`). Размерности — над $\mathbb F_2$.

**Утверждение 4 (потомки шага $s$).** Всякий непосредственный потомок $H$ вершины $V$ шага $s$
изоморфен $V^*/U$, где $U \le M$, $|M : U| = 2^s$ и $NU = M$.

*Доказательство* — как утверждение 1 в `../pq1024/README.md`, с $2^s$ вместо 2. $P_{c+1}(H) \le \Phi(H)$,
поэтому $d(H) = d$, и прообразы порождающих $V$ дают эпиморфизм $F \to H$ над $F \to V$ с ядром
$L \le K$. $K/L = P_{c+1}(H)$ центральна ($[P_{c+1}, H] \le P_{c+2}(H) = 1$) и элементарна
($P_{c+1}^2 \le P_{c+2} = 1$), так что $[K,F]K^2 \le L$ и $H \cong V^*/U$, $U = L/[K,F]K^2$,
$|M/U| = 2^s$. Члены нижнего экспоненциально-2 центрального ряда переходят в образы:
$P_{c+1}(V^*/U) = NU/U$; а $P_{c+1}(H) = M/U$ (это слой порядка $2^s$, $H/P_{c+1}(H) \cong V$). Значит,
$NU = M$. $\square$

Отсюда $s = \dim M/U = \dim N - \dim(N \cap U) \le \dim N$.

**Правило 0 (терминальность).** Если $N = 0$, потомков нет ни одного шага. *Доказательство:*
$NU = U \ne M$ при $s \ge 1$. $\square$

**Правило 1 (класс $\le 3$).** Потомок класса $\le 3$ шага $s$ возможен только при
$s \le \nu_4 = \dim(N + G_4) - \dim G_4$, $G_4 = \gamma_4(V^*)$.
*Доказательство.* $\gamma_4(V) = 1$, поэтому $G_4 \le M$, и
$\gamma_4(V^*/U) = G_4U/U = 1 \iff G_4 \le U$. Тогда $N \cap U \supseteq N \cap G_4$ и
$s = \dim N - \dim(N \cap U) \le \dim N - \dim(N \cap G_4) = \nu_4$. $\square$

**Правило 2 (следствие 1).** Пусть ищутся кандидаты порядка $\le 2^{N}$ (`LOGQ`). Если
$d + 4(e_V + 1) + 2 > N$, то потомок, который обход оставит, лежит над $G = G_4 + (\gamma_3(V^*) \cap M)$,
и шаг ограничен $\nu = \dim(N + G) - \dim G$.
*Доказательство.* Пусть $A_3 = \gamma_3(V^*) \cap M$, $H = V^*/U$. По модулярному закону
$\gamma_3(H) \cap (M/U) = (A_3 + U)/U$, а $\gamma_3(H)/(\gamma_3(H) \cap M/U) \cong \gamma_3(V)$; значит,
$|\gamma_3(H)| = 2^{e_V}\,|(A_3+U)/U|$. Если $A_3 \not\le U$, то $H$ класса 3 и $e_H \ge e_V + 1$, то есть
$d + 4e_H + 2 > N$. Но левая часть — это грубая нижняя оценка величины `bud` из (Г$_N$) (раздел
«Следствие»: она получается из самих инвариантов $H$, без кандидата), поэтому `PR_Data(H, N).p5b`
ложно, и обход без правил отбросил бы $H$ сам. Итак, $A_3 \le U$ и $G_4 \le U$; дальше — как в
правиле 1. $\square$

**Правило 3 (последний уровень).** Потомки порядка $2^{\mathrm{NMAX}}$ обход не раскрывает; они нужны
только как родители, то есть при $2$-классе $\ge 3$. У потомка $2$-класс $c + 1$, поэтому при
$c = 1$ (элементарная абелева $V$) шаг $\mathrm{NMAX} - k$ не нужен.

Все четыре правила отбрасывают только тех потомков, которых обход без правил тоже отбросил бы
или не использовал. Поэтому родители и кандидаты те же; меняется лишь счётчик `vert` на
последнем уровне (не порождаются потомки $p$-класса 2, которые и раньше никуда не шли).

## p-накрытие без pq

`PqPCover` (ANUPQ) стоит ≈ 22–28 мс на группу порядка 512 и вызывается по разу на вершину в
`steps.g` и на родителя в поиске через накрытие. Профиль (`prof_vertex.g`): 15 мс — сторона GAP
(запись копредставления, чтение файла результата, сборка группы), 7 мс — процесс `pq`. Одна сессия
`pq` на кусок сэкономила бы не больше 7 мс; `pcover.g` убирает `PqPCover` целиком: $G^*$ строится как
расширение $G$ двойственным к $H^2(G, \mathbb F_2)$ (утверждение 5 и доказательство — в README.md,
раздел "The p-cover without pq"). Включается флагом `OWNCOVER` (переменная окружения
`PQ2048_OWNCOVER=1`), по умолчанию — прежнее поведение.

Сверка с `PqPCover` на всех вершинах порядков 8–256 и на выборках порядка 512 (39 846 вершин,
6 916 родителей): тот же порядок накрытия, те же решения `steps.g`, те же числа допустимых
гиперплоскостей и те же кандидаты с точностью до изоморфизма — **0 расхождений**. `steps.g`:
21–25 → 5–10 мс на вершину, `MC_Data`: 23–29 → 7–10 мс на родителя. Обход рангов 2–4 до 256 и
кусок ранга 6 (211 вершин порядка 512): те же счётчики и кандидаты; ранг 4 — 137,6 → 103,4 с,
кусок ранга 6 — 219,6 → 171,7 с. В куске ранга 6 остальное время — раскрытие одной вершины с 2 240
потомками: `PqDescendants` 110 с (из них 90 с — сборка потомков на стороне GAP, ≈ 40 мс на
потомка) и `PR_Data` 25,6 с. $\mathrm{Aut}$ дёшев (≈ 60 мс на раскрываемую вершину), кэшировать его
незачем. Следующий шаг — порождать потомков шага 1 самим, как $V^*/U$ по орбитам $\mathrm{Aut}(V)$
на гиперплоскостях $M$, без обратного пути через fp-копредставления.

## Не доказано

Условия, которые выглядят верными, но **не доказаны** и для отсева не используются:

1. **Потомки шага 1 вершин $p$-класса 2 ранга 5 порядка 512 не проходят (Г$_{11}$).** В выборке —
   0 из 3028 (40 вершин). *Под сомнением после выборки с правилами шагов* (раздел «Вершины без потомков»: 254
   раскрытые вершины ранга 5 дали 2008 таких потомков; $p$-класс этих вершин там не записан). Если это теорема (например, через следствие 1: родитель класса 3 при
   $d = 5$ должен иметь $R_{ab} \cong \mathbb Z/4^2 \oplus \mathbb Z/2^3$, $|X| = 4$,
   $\gamma_2 \cap Z = \gamma_3 \cong \mathbb Z/4$ — все грубые оценки обращаются в равенства;
   для родителя класса 2 нужен отдельный довод), то ранг 5 раскрывать надо только с вершин
   $p$-класса $\ge 3$ (≈ 48 тыс. вместо 5,9 млн), и ранг 5 стоит часы, а не месяцы. Это
   главный кандидат на следующее доказательство.
2. **Предсказание по накрытию вершины.** Условие (Г$_{11}$) на ребёнке $R = V^*/U$ проверяется
   только после `PqDescendants(V)`. Двухуровневый линейный тест на $p$-накрытии $V$ (как
   в переборе через $p$-накрытие для $Q = R^*/U$) мог бы отбрасывать $V$ без $\mathrm{Aut}(V)$; не сделано.
3. **Сведение для центральных произведений.** Большой ранг при циклическом центре даётся
   центральными произведениями с экстраспециальными группами ($H \circ E$). Если бы
   $D_5(H \circ E) = 1$ следовало из $D_5(H) = 1$, ранги $\ge 5$ отпали бы целиком. Функториальность
   даёт только включение образа, $D_5(G) \twoheadrightarrow$ не следует; утверждение не доказано
   и не проверялось.
4. **$\mathrm{rk}\,\gamma_2(Q) \le d$** — неверно: на порядке 512 встречается
   $\mathrm{rk}\,\gamma_2(Q) = d + 1$ (`results/small/cands_512.json`, `r2_minus_d` = 1), так что
   «$+1$» в (Г3) нужен.
5. **Известные результаты о $D_4$ для малого класса.** Контрпример обязан иметь $D_4(Q) \ne 1$.
   Если бы было доказано, что $D_4 = \gamma_4$ для 2-порождённых групп или при каком-то условии на
   $Q_{ab}$ (направление Rips / Tahara / Losey / Hartley, обзор Mikhailov–Passi, LNM 1952), это дало
   бы отсев по рангу или по типу $Q_{ab}$ ($Q_{ab} = R_{ab}$ видна на родителе). Такие утверждения
   мы в источниках **не проверяли** †; в статье (в подготовке) из этой области используются только
   $D_4^2 \subseteq \gamma_4$ (Passi), граница Тахары и Gupta–Tahara для нечётного $p$.

† — не проверено по источнику.
