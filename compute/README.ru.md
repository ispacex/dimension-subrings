# compute — точное вычисление целочисленных размерных подгрупп малых $p$-групп

Вычислительная разведка к задаче 20.84 Коуровской тетради
(V. Ionin, R. Mikhailov, T. Petrov, *Dimension subrings of Lie rings*, arXiv:2610.02042):
**верно ли $D_5(G) \subseteq \gamma_4(G)$ для всякой группы $G$**, и бывает ли 3-кручение
в $D_5(G)/\gamma_5(G)$. Здесь $D_n(G) = G \cap (1 + \Delta^n)$, $\Delta$ — аугментационный
идеал $\mathbb Z[G]$, $\gamma_n$ — нижний центральный ряд ($\gamma_1 = G$).

Итоги и таблицы — в [`results/SUMMARY.ru.md`](results/SUMMARY.ru.md) и `results/*.csv`.

## Метод

### Координаты

$\mathbb Z[G] = \mathbb Z\cdot 1 \oplus \Delta$, у $\Delta$ базис $\{g - 1 : g \ne 1\}$; элемент
$\Delta$ — вектор его коэффициентов при $g \ne 1$ (коэффициент при $1$ — минус их сумма).
Значит, $g \in D_n(G) \iff$ единичный вектор $e_g$ лежит в решётке $\Delta^n \subseteq \mathbb Z^{|G|-1}$.
Решётка $\Delta^n$ полного ранга $|G|-1$ (над $\mathbb Q$ аугментационный идеал полупростой
алгебры идемпотентен), так что $\Delta/\Delta^n$ — конечная абелева группа.

### Построение $\Delta^n$ (метод A) и его доказательство

Пусть $x_1, \dots, x_d$ порождают $G$ (в коде — `MinimalGeneratingSet` из GAP),
$b_1, \dots, b_r$ порождают $\Delta^{n-1}$ как абелеву группу. Тогда

$$\Delta^n = \operatorname{span}_{\mathbb Z}\{\, b_k (x_i - 1) \,\}.$$

*Доказательство.* (1) $\Delta = \sum_i \mathbb Z[G](x_i - 1)$ — левый идеал, порождённый
$x_i - 1$. Действительно, конечная $G$ порождается $x_i$ как моноид ($x^{-1} = x^{|x|-1}$),
и для слова $g = h x_i$ имеем $g - 1 = h(x_i - 1) + (h - 1)$; индукция по длине слова.
(2) $\Delta^{n-1}$ — двусторонний идеал, поэтому $\Delta^{n-1}\mathbb Z[G] = \Delta^{n-1}$.
(3) $\Delta^n = \Delta^{n-1}\Delta$ (произведение аддитивных подгрупп = линейная оболочка
произведений) $= \operatorname{span}\{a\, r\, (x_i - 1) : a \in \Delta^{n-1}, r \in \mathbb Z[G]\}
= \operatorname{span}\{a' (x_i - 1) : a' \in \Delta^{n-1}\}$ по (2), и по билинейности достаточно
$a'$ из системы образующих $b_k$. $\square$

Замечание к постановке: если умножать **справа** на $(x_i - 1)$, замыкание не нужно —
нужен левый идеал, порождённый $x_i - 1$, а он и есть $\Delta$. (Вариант «$\Delta$ как правый
идеал, $\Delta^{n-1}(x_i-1)$ и замыкание умножением справа на $G$» тоже верен, но дороже;
первая версия кода так и считала, результаты совпали.) В режиме `--full` код дополнительно
проверяет, что полученная решётка замкнута относительно умножения справа на образующие и на
элементы Pcgs — то есть что это действительно идеал.

### Арифметика по модулю $p^E$ — точная, а не приближённая

Все решётки берутся по модулю $D\Delta$, $D = p^E$ ($E = 30, 19, 13$ для $p = 2, 3, 5$:
$D < 2^{31}$, так что произведение двух вычетов помещается в `int64`). $D\Delta$ —
двусторонний идеал, поэтому образ $\Delta^n$ в $\Delta/D\Delta$ порождается образами тех же
произведений, и вычисление по модулю $D$ даёт ровно $L_n = (\Delta^n + D\Delta)/D\Delta$.

* **Непринадлежность всегда точна.** Если $g - 1 \notin \Delta^n + D\Delta$, то
  $g - 1 \notin \Delta^n$, т. е. $g \notin D_n$. Поскольку $\gamma_n \subseteq D_n$ — теорема,
  равенство $D_n = \gamma_n$ доказывается так: все $g \notin \gamma_n$ не лежат в $L_n$.
  Никакой оценки на $E$ для этого не нужно.
* **Принадлежность точна при сертификате.** Если $p^{E-1}\Delta \subseteq \Delta^n + D\Delta$
  (проверка: $p^{E-1} e_c \in L_n$ для всех $c$; функция `certified`), то $D\Delta \subseteq \Delta^n$.
  Доказательство: пусть элементарные делители $\Delta/\Delta^n$ равны $p^{a_j}$; тогда у
  $\Delta/(\Delta^n + D\Delta)$ они $p^{\min(a_j, E)}$, и показатель этой группы $\le p^{E-1}$
  влечёт $a_j \le E-1$ для всех $j$, т. е. $p^{E-1}\Delta \subseteq \Delta^n$. Тогда
  $L_n$ — образ самой $\Delta^n$ и принадлежность по модулю $D$ есть принадлежность $\Delta^n$.
  Сертификат считается всегда в режиме `--full` и в быстром режиме — когда $D_n \ne \gamma_n$
  (там он нужен, чтобы лишний элемент был настоящим). Во всех полных прогонах он проходил.

### Форма Хауэлла над $\mathbb Z/p^E$

`howell()` приводит систему строк к ступенчатому виду: строка $i$ начинается в столбце $c_i$
с элемента $p^{v_i}$, столбцы возрастают. Шаг по столбцу $c$: из оставшихся строк берём
строку с минимальной $p$-адической оценкой в столбце $c$, нормируем обратимым множителем,
вычитаем её кратные из остальных (это возможно: их оценки не меньше) и **добавляем в пул
строку $p^{E-v}\cdot(\text{опорная})$** — она обнуляется в столбце $c$.

*Свойство Хауэлла:* всякий элемент оболочки, равный нулю в столбцах $< c$, лежит в оболочке
строк с $c_i \ge c$. Индукция по столбцам: если $x = a\cdot\text{piv} + y$, $y$ из нового
пула (нули в столбце $c$) и $x_c = 0$, то $a\,u\,p^{v} \equiv 0 \pmod{p^E}$, т. е.
$p^{E-v} \mid a$, и $a\cdot\text{piv}$ — кратное добавленной строки. Отсюда корректность
проверки принадлежности `reduce_rows`: столбец за столбцом коэффициент обязан делиться на
$p^{v_i}$, а в конце остаток обязан быть нулём. Порядок решётки $|L_n| = \prod p^{E - v_i}$,
отсюда $\log_p[\Delta : \Delta^n + D\Delta]$ в выводе (`index_logp`).

### Быстрый режим

$D_n \subseteq D_{n-1}$, поэтому на шаге $n$ проверяются только элементы $D_{n-1}$; как только
$D_n = 1$, все дальнейшие $D_k = 1 = \gamma_k$ и счёт останавливается. Для группы класса $c$
с $D_k = \gamma_k$ это значит, что считаются $\Delta^2, \dots, \Delta^{c+1}$. Индекс
$[\Delta:\Delta^n]$ в быстром режиме печатается без сертификата (помечен `?` в CSV) —
это индекс $\Delta^n + p^E\Delta$.

## Проверки корректности (все прошли до перебора)

1. **$\gamma_n \subseteq D_n$** проверяется на каждом уровне каждой группы (иначе исключение).
2. **$D_1 = G$, $D_2 = \gamma_2$, $D_3 = \gamma_3$** — на всех посчитанных группах.
3. **Метод B** (`--method B`): $\Delta^n = \operatorname{span}\{(y-1)\,b_k : y \in S\}$, где $S$ —
   объединение классов сопряжённости элементов **Pcgs** (другая система образующих), умножение
   **слева**, другие таблицы (левое регулярное действие строится BFS из правого).
   Доказательство: $\Delta^n = \Delta\cdot\Delta^{n-1} = \operatorname{span}\{(g-1)c : g \in G,\ c \in \Delta^{n-1}\}$,
   и $(g - 1)c$ лежит в $R = \operatorname{span}\{(y-1)c' : y \in S,\ c' \in \Delta^{n-1}\}$ по индукции
   по длине $g$ как слова в $S$: $(gy - 1)c = (gyg^{-1} - 1)(gc) + (g - 1)c$, где $gyg^{-1} \in S$
   ($S$ замкнуто относительно сопряжения) и $gc \in \Delta^{n-1}$.
   Сравнение A и B в полном режиме: $|D_n|$, множества лишних элементов и индексы
   $[\Delta : \Delta^n]$ для $n \le 6$.
4. **Метод C** (`method_c.py`, PARI/GP 2.17, точно над $\mathbb Z$, без модуля):
   $\Delta^n = $ `mathnf` от $\{b(g - 1) : g \in G\}$ — **все** $g$, без образующих, по полной
   таблице умножения (отдельный экспорт `export_table.g`); принадлежность — «HNF не меняется
   от добавления вектора»; индекс — $|\det|$ HNF без строки единицы. Совпадение с A по $|D_n|$
   и по сертифицированным индексам.
5. **Известные значения:** для циклической $C_m$ $\Delta^n/\Delta^{n+1} \cong C_m$ (индексы
   растут на $\log_p m$ за шаг: у $C_{16}$ — $4, 8, 12, 16, 20$); $\Delta/\Delta^2 \cong G_{ab}$;
   у $C_2^4$ $|\Delta^2/\Delta^3| = 2^{10}$.
6. **$D_n = 1$ при больших $n$.** Для конечной $p$-группы это следует из теоремы Дженнингса
   (без ссылок на $\bigcap\Delta^n$): гомоморфизм $\mathbb Z[G] \to \mathbb F_p[G]$ переводит
   $\Delta^n$ в $\Delta_{\mathbb F_p}^n$, значит $D_n(G) \subseteq D_n(G;\mathbb F_p) = M_n(G)$
   (ряд Дженнингса, S. A. Jennings, *The structure of the group ring of a p-group over a
   modular field*, Trans. AMS 50 (1941) 175–185), а $M_n = 1$ при $n$ больше длины ряда
   (поле $\mathbb F_p$, $\Delta_{\mathbb F_p}$ нильпотентен). Счёт везде доходил до $D_n = 1$.
   Утверждение «$\bigcap_n \Delta^n = 0$ в $\mathbb Z[G]$ для конечной $p$-группы» тоже верно
   (Gruenberg 1957; см. I. B. S. Passi, *Group Rings and Their Augmentation Ideals*, LNM 715) †
   — но им мы не пользуемся. († — ссылка по памяти, страницы не сверены.)

## Сведение главного вопроса к метабелевым 2-группам класса 3 (перепроверено)

Сведение перепроверено; одно уточнение в (c).

**Утверждение.** $D_5(G) \subseteq \gamma_4(G)$ для всех групп $\iff$ $D_5(M) = 1$ для всех
конечных метабелевых 2-групп $M$ класса $\le 3$ (содержательно — класса ровно 3).

(a) $G'' = [\gamma_2, \gamma_2] \subseteq \gamma_4$ (так как $[\gamma_i, \gamma_j] \subseteq \gamma_{i+j}$),
поэтому $M = G/\gamma_4(G)$ метабелева класса $\le 3$. $D_n$ функториальна (образ $D_n(G)$ лежит
в $D_n(G/N)$), значит $D_5(M) = 1 \Rightarrow D_5(G) \subseteq \gamma_4(G)$. Обратно: если
$D_5(M) \ne 1$ при $\gamma_4(M) = 1$ — это контрпример.
(b) $x - 1$ — конечная комбинация произведений пяти множителей $g - 1$; все они в $\mathbb Z[H]$
для конечно порождённой $H \ni x$, и $x \in D_5(H)$. $H$ — метабелева класса $\le 3$.
(c) $D_4^2 \subseteq \gamma_4$ (Passi, 1968) и $\gamma_4(H) = 1$, так что $x^2 = 1$.
*Уточнение:* применять это нужно к $H$ (а не к $M$): $x \in D_5(H) \subseteq D_4(H)$, $x^2 \in \gamma_4(H) = 1$.
(d) $H$ — к. п. нильпотентная; $T$ — её элементы нечётного порядка (конечная нормальная
подгруппа); $x \notin T$ (порядок 2). У $H/T$ кручение — 2-группа, по Грюнбергу (Proc. LMS 7
(1957) 29–62) она аппроксимируется конечными 2-группами; найдётся конечный 2-фактор $Q$, где
образ $x$ нетривиален и лежит в $D_5(Q)$; $Q$ метабелева класса $\le 3$. $\square$

**Следствие для конечных групп (порядок не растёт).** Если $G$ конечна, то в (b)–(d) $H \le M$,
$M$ конечная нильпотентная, $M = P \times T$, и $Q = P$ — силовская 2-подгруппа $M$, т. е.
2-группа порядка $\le$ 2-части $|G|$. Поэтому **проверка всех метабелевых 2-групп класса 3
порядка $\le 2^k$ доказывает $D_5 \subseteq \gamma_4$ для всех конечных групп, у которых
2-часть порядка $\le 2^k$** (в частности, для всех групп порядка $< 2^{k+1}$).

То же рассуждение для произвольного $n$: если у всех $p$-групп порядка $\le X_p$ выполнено
$D_n = \gamma_n$ при всех $n$, то $D_n(G) = \gamma_n(G)$ при всех $n$ для всякой конечной $G$,
у которой $p$-часть порядка $\le X_p$ при каждом $p$ (переходим к $G/\gamma_n(G) = \prod_p P_p$,
образ $x \in D_n$ в каждом $P_p$ лежит в $D_n(P_p) = \gamma_n(P_p) = 1$).

### Сита, которыми пользуется перебор (все — теоремы, не эвристики)

* **Класс $\le 2$:** $D_n = \gamma_n$ при всех $n$, так как $D_3 = \gamma_3 = 1$ (и $D_1$, $D_2$
  — классика). Такие группы порядка 256 не считаются решёткой.
* **Класс $\le$ $p$-класс.** Для нижнего экспоненциально-2 центрального ряда
  $P_1 = G$, $P_{i+1} = [P_i, G]P_i^2$ имеем $\gamma_i \subseteq P_i$, а $p$-класс $c$ означает
  $P_{c+1} = 1$; значит, у групп $p$-класса 2 класс $\le 2$. `SmallGroupsInformation(512)`
  перечисляет id по рангу и $p$-классу, и сито (`sieve512.sh`) идёт по всем диапазонам
  $p$-класса $\ge 3$ — 1 708 439 групп из 10 494 213. (Первая версия сита ошибочно отбросила и
  $p$-класс 3 — ошибка на единицу в определении; исправлено, прогон повторён целиком.)
* **Сито Дженнингса** (`filter_metab3.g`): для метабелевой группы класса 3
  $D_5 \subseteq D_3 \cap M_5 = \gamma_3 \cap M_5$ и (по (c)) $D_5 \subseteq \Omega_1$ (элементы
  порядка $\le 2$; $\gamma_3$ центральна, так что это подгруппа). Если
  $K = \Omega_1(\gamma_3 \cap M_5) = 1$, то $D_5 = 1$ без решёток; иначе группа идёт в
  решёточный счёт.
* **3-кручение в $D_5/\gamma_5$.** Для 3-групп $D_4 = \gamma_4$ ($D_4/\gamma_4$ — 2-группа по
  Пасси). Аналогично (a)–(d) с $N = \gamma_5(G)$ (метабелевость здесь не получается:
  $G''\subseteq\gamma_4$, но не $\gamma_5$) элемент порядка 3 в $D_5/\gamma_5$ где-либо даёт
  конечную 3-группу класса $\le 4$ с $D_5 \ne 1$ (у к. п. нильпотентной $H$ убиваем элементы
  порядка, взаимно простого с 3, и аппроксимируем конечными 3-группами по Грюнбергу; для
  конечной $G$ — силовская 3-подгруппа $G/\gamma_5$). При классе $\le 3$ $D_5 \subseteq D_4 = \gamma_4 = 1$,
  так что содержательны 3-группы класса ровно 4. 3-группы порядка $\le 3^6$ считаются все.
* **$p \ge 5$.** $D_4/\gamma_4$ — 2-группа, $D_5/\gamma_5$ имеет показатель, делящий 6
  (Тахара), так что для 5-групп $D_n = \gamma_n$ при $n \le 5$ автоматически, а у групп
  порядка $5^5$ класс $\le 4$ и $D_6 \subseteq D_5 = \gamma_5 = 1$. Порядок $5^5$ поэтому не
  считается; $5^4$ посчитан как проверка.

## Как запустить

Самая малая проверка требует только Python 3 с NumPy: в `examples/order16.jsonl` — 14 групп
порядка 16, выгруженных `export.g`, и

```bash
python3 dimsub.py A < examples/order16.jsonl          # по строке JSON на группу: D_n и gamma_n по уровням
python3 dimsub.py B --full < examples/order16.jsonl   # метод B, полный режим с сертификатами
```

Общий путь:

```bash
# окружение (без root, в домашней папке):
micromamba create -p ./env -c conda-forge gap-defaults pari python=3.12 numpy python-flint
./run_export.sh 64 1 267 all data/g64.jsonl           # ORDER IDFROM IDTO FILTER OUT
env/bin/python run.py data/g64.jsonl out/A64.jsonl --jobs 8          # быстрый режим
env/bin/python run.py data/g64.jsonl out/F_A64.jsonl --full --jobs 8 # полный режим
env/bin/python run.py data/g64.jsonl out/F_B64.jsonl --full --method B
printf 'ORDER:=64;; IDS:=[1..267];; OUTFILE:="chk/t64.jsonl";;\n' | cat - export_table.g | env/bin/gap -q -b
env/bin/python method_c.py 6 < chk/t64.jsonl > chk/c64.gp && env/bin/gp -q chk/c64.gp > chk/C64.txt
env/bin/python compare.py out/F_A64.jsonl out/F_B64.jsonl chk/C64.txt
./run_sieve.sh 512 11 2044 sieve/c512_11.jsonl sieve/s512_11.json
env/bin/python aggregate.py results/order64.csv out/A64.jsonl
```

Версии: GAP 4.15.1, SmallGroups (smallgrp) 1.5.4, PARI/GP 2.17.3, Python 3.12, NumPy 2.5.4
(python-flint 0.8.0 поставлен, но не понадобился). Всё — conda-forge через micromamba.
Сырые данные (`data/`, `out/`,
`sieve/`, `chk/`) в git не входят — они воспроизводятся командами выше.
