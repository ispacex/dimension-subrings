# magnus — truncated Magnus algebra and the 3-torsion sieve

Two side computations: whether the class-3 2-quotients of a Rips-type family have $D_5 = 1$,
and an improved sieve for 3-torsion in $D_5/\gamma_5$ on 3-groups of class 4. Run from this directory;
`magnus.py` imports `Ring`, `howell`, `reduce_rows` from `../dimsub.py` unchanged.

| File | What |
|---|---|
| `magnus.py` | `Z[G]/Delta^n = T_{<n}(Z^k)/I_n`: membership in `D_n` modulo `2^E` (Howell form). Non-membership is exact, membership only necessary |
| `rips3.py` | `alpha = [e0,e1]^32 [e0,e2]^64 [e1,e2]^128` in the 3-relator group of Bartholdi–Mikhailov (arXiv:1805.10894, §1.2) |
| `bm91.py`, `bm91_n4.log` | check of the method on the 15-generator group of BM §9.1 (`omega` in `D_4`) |
| `fam.g` | GAP: the Rips-type family `Q = G/gamma_4(G)`, its order and generators of `Omega_1(gamma_3 ∩ M_5)` as words |
| `fam_run{1,2,3}.g` | parameter sets of the family (write `fam{1,2,3}.jsonl`, not kept: regenerate) |
| `famd5.py`, `famd5.log` | `D_5(Q)` for those groups: `cat fam*.jsonl \| python famd5.py` |
| `pcl.g` | check that the 2-quotient is all of `G/gamma_4(G)` (p-class below the bound) |
| `e1.g`, `e1.log`, `e1_*.csv`, `e1b.*` | E1: improved sieve for 3-groups of class 4, orders 3^5–3^7 |
| `e2.g`, `e2.log`, `bm_def.g`, `3group.gap` | derived series and rank of the large 3-groups (GAP pc definitions) |
| `nq1.g`, `t.g` | scratch checks |
| `liedim.py` | Lie rings (MATH-42): $\delta_n(L)/\gamma_n(L)$ for a finitely presented Lie ring with weighted generators, as $K/J$ inside $U(L)/\varpi^n = T_{<n}/I$ in the Lyndon basis, modulo $p^E$; prints the free rank, $\log_p$ of the torsion and its exponent |
| `lie_bm2.py`, `lie_bm2_honest.py` | check: BM §9.1 2-torsion Lie ring, $\delta_4/\gamma_4 \cong \mathbb Z/2$, with a degree-2 generator as one weighted letter and as $[z, z']$ of fresh generators (both give $\mathbb Z/2$) |
| `lie_bm2_n5.py` | positive control at $n = 5$: the same ring with $y_{0j}$ of degree 3, $\delta_5/\gamma_5 \cong \mathbb Z/2$ |
| `lie_search5.py` | random search for 3-torsion in $\delta_5/\gamma_5$ over BM (9.1)-type rings: `python lie_search5.py SEED COUNT [E\|-] [wide\|212]`, one JSON line per ring |
| `lie_bm3.py` | positive control for 3-torsion: BM (9.1) at $n = 7$ (`python lie_bm3.py 3` — the length-3 block, 3 s): $\delta_7/\gamma_7 \cong \mathbb Z/3$ there, generated by $\omega = 3^9[e_2,e_1,e_0]$, $3\omega \in \gamma_7$, $\omega/3 \notin \delta_7$ (BM Prop. 9.1) |
| `lie_grid5.py`, `lie_grid5.jsonl` | grid over the (9.1) pattern at $n = 5$: $3^{a_k} f_k = y_k$, $f_i \pm f_j = 3^c y_{ij}$ on 01, 02, 13, 23; $a \in \{0..3\}^4$, $c \in \{0..4\}$, pair weight 1–3, 7168 rings |
| `lie_imp_l1.py`, `lie_imp_l1_*.jsonl` | the metabelian ring $L_1$ of IMP26 (sec. "Finite plateaux"): `python lie_imp_l1.py 2` gives $\delta_5 = \langle 2^5 u_3\rangle \cong \mathbb Z/2$; with 3 in place of 2 and with local perturbations (`... 3 search SEED COUNT local`) a metabelian search for 3-torsion |
| `lie_search5.jsonl` | its output: seeds 1–6 × 400 (base), 201–202 × 150 (`wide`), 301–302 × 25 (`212`), $E = 19$; all 2750 rings have $\delta_5 = \gamma_5$ |

The `*.log` files named above are not kept in git (`../.gitignore`); rerunning the scripts writes them.

GAP 4.15 with SmallGroups; Python 3.12 with numpy.
