# magnus — truncated Magnus algebra and the 3-torsion sieve

Two side computations: whether the class-3 2-quotients of a Rips-type family have $D_5 = 1$,
and an improved sieve for 3-torsion in $D_5/\gamma_5$ on 3-groups of class 4. Run from this directory;
`magnus.py` imports `Ring`, `howell`, `reduce_rows` from `../dimsub.py` unchanged.

| File | What |
|---|---|
| `magnus.py` | `Z[G]/Delta^n = T_{<n}(Z^k)/I_n`: membership in `D_n` modulo `2^E` (Howell form). Non-membership is exact, membership only necessary |
| `rips3.py` | `alpha = [e0,e1]^32 [e0,e2]^64 [e1,e2]^128` in the 3-relator group of Bartholdi–Mikhailov (arXiv:1805.10894, §1.2) |
| `bm91.py`, `bm91_n4.log` | check of the method on the 15-generator group of BM §9.1 (`omega` in `D_4`) |
| `fam.g` | GAP: the Rips-type family `Q = G/gamma_4(G)`, its order and generators of `Omega_1(gamma_3 ∩ M_5)` as words |
| `fam_run{1,2,3}.g` | parameter sets of the family (write `fam{1,2,3}.jsonl`, not kept: regenerate) |
| `famd5.py`, `famd5.log` | `D_5(Q)` for those groups: `cat fam*.jsonl \| python famd5.py` |
| `pcl.g` | check that the 2-quotient is all of `G/gamma_4(G)` (p-class below the bound) |
| `e1.g`, `e1.log`, `e1_*.csv`, `e1b.*` | E1: improved sieve for 3-groups of class 4, orders 3^5–3^7 |
| `e2.g`, `e2.log`, `bm_def.g`, `3group.gap` | derived series and rank of the large 3-groups (GAP pc definitions) |
| `nq1.g`, `t.g` | scratch checks |
| `liedim.py` | Lie rings (MATH-42): $\delta_n(L)/\gamma_n(L)$ for a finitely presented Lie ring with weighted generators, as $K/J$ inside $U(L)/\varpi^n = T_{<n}/I$ in the Lyndon basis, modulo $p^E$; prints the free rank, $\log_p$ of the torsion and its exponent |
| `lie_bm2.py`, `lie_bm2_honest.py` | check: BM §9.1 2-torsion Lie ring, $\delta_4/\gamma_4 \cong \mathbb Z/2$, with a degree-2 generator as one weighted letter and as $[z, z']$ of fresh generators (both give $\mathbb Z/2$) |
| `lie_bm2_n5.py` | positive control at $n = 5$: the same ring with $y_{0j}$ of degree 3, $\delta_5/\gamma_5 \cong \mathbb Z/2$ |
| `lie_search5.py` | random search for 3-torsion in $\delta_5/\gamma_5$ over BM (9.1)-type rings: `python lie_search5.py SEED COUNT [E\|-] [wide\|212]`, one JSON line per ring |
| `lie_bm3.py` | positive control for 3-torsion: BM (9.1) at $n = 7$ (`python lie_bm3.py 3` — the length-3 block, 3 s): $\delta_7/\gamma_7 \cong \mathbb Z/3$ there, generated by $\omega = 3^9[e_2,e_1,e_0]$, $3\omega \in \gamma_7$, $\omega/3 \notin \delta_7$ (BM Prop. 9.1) |
| `lie_grid5.py`, `lie_grid5.jsonl` | grid over the (9.1) pattern at $n = 5$: $3^{a_k} f_k = y_k$, $f_i \pm f_j = 3^c y_{ij}$ on 01, 02, 13, 23; $a \in \{0..3\}^4$, $c \in \{0..4\}$, pair weight 1–3, 7168 rings |
| `lie_imp_l1.py`, `lie_imp_l1_*.jsonl` | the metabelian ring $L_1$ of IMP26 (sec. "Finite plateaux"): `python lie_imp_l1.py 2` gives $\delta_5 = \langle 2^5 u_3\rangle \cong \mathbb Z/2$; with 3 in place of 2 and with local perturbations (`... 3 search SEED COUNT local`) a metabelian search for 3-torsion. By Passi–Sicking (arXiv:1602.04919, Thm 1: $2\delta_n(L) \subseteq \gamma_n(L)$ for metabelian $L$) every $q = 3$ run here is 0 a priori: it checks the calculator, not the question |
| `lie_nonmet5.py`, `lie_nonmet5.jsonl` | MATH-119: searches with $L''$ left free in weight 4, where odd torsion of $\delta_5/\gamma_5$ must live (Passi–Sicking + functoriality): `unmet` = the $L_1$ pattern without $L'' = 0$, weight-4 elements $[[x_a,x_b],[x_c,x_d]]$ free / killed / tied to $q^k u_3$ (`python lie_nonmet5.py unmet Q` for all free); `rips2` = $q^{a_i}x_i = \sum \pm q^b [x_j,x_l]$ on 3–4 generators plus torsion relators. Output: `rips2` $q=3$ 4×300 and $q=2$ 300, `unmet` $q=3$ and $q=2$ 300 each; only `unmet` $q=2$ has torsion ($\mathbb Z/2$ in 142 of 300), everything else 0. `rips2` has no positive control at $q=2$, so it is weak evidence |
| `c38.g` | MATH-120: sieve over all 3-groups of order $3^8$ (`SmallGroup(3^8, i)`, package `sglppow`): rank 3–4, class 4, $Q'' \ne 1$, cyclic centre, $\Omega_1(Z) \subseteq Q'' \cap M_5$; writes a CSV line per non-metabelian class-4 group and, per survivor, a presentation on a minimal generating set (Tietze from the pc presentation) with the socle generator `z` as a word |
| `d5z.py` | MATH-120: `python d5z.py [E] < c38_*.jsonl` — is `z` in $D_5$? Truncated Magnus algebra modulo $3^E$; non-membership exact, membership exact when the certificate $3^{E-1}\Delta \subseteq \Delta^5 + 3^E$ holds; controls `z` in $D_4$, generators not in $D_2$ |
| `presgens.g` | `PresOnGens(G, gens)`: presentation of a pc group on given generators by Tietze from the pc presentation (no coset enumeration); read by `c38.g`, `c39.g` |
| `chk38.g` | checks the presentations of a `c38`/`c39` JSON file with ANUPQ: 3-quotient of order `CHKORDER` (default $3^8$), class 4, `z` central of order 3 in $Q'' \cap M_5$ (set `CHKIN`) |
| `run_chk39.sh` | `chk38.g` on the `cand_*.jsonl.gz` of a `run_c39all.sh` job (`CANDDIR`), one GAP per file |
| `c38_3e8.csv`, `d5z_3e8.csv` | results for order $3^8$: the 904 non-metabelian class-4 groups (id, $d$, $\log_3$ of the lower central factors, $\lvert Q''\rvert$, $\lvert Q''\cap M_5\rvert$, $\lvert Z\rvert$, cyclic, survivor) and `d5z.py` on the 699 survivors (all `z_in_D5 = False`, certified) |
| `est39.g` | order $3^9$ estimate: `PqDescendants(P : StepSize := 1)` for random parents $P$ of order $3^8$ (set `RANGES`, `PER`), counts class-4 non-metabelian descendants with cyclic centre |
| `c39.g` | order $3^9$: step-1 descendants of the parents in `PARENTS` through the `c38` sieve, presentations for `d5z.py` (ids `"parent.descendant"`); `C39Pass(P)`: a test on the p-cover $P^*$ (multiplier $M$, nucleus $N$) — if $M \cap P^{*\prime\prime}$, $M \cap M_5(P^*)$ or $N$ lies in $\gamma_5(P^*)$, no step-1 descendant is a candidate |
| `v39.g` | checks `C39Pass` against `C39One` on `IDS` or on `NSAMPLE` random ids (seed `SEED`), wall-clock times of both |
| `r5.g`, `run_r5.sh` | order $3^9$, part $d=5$: the parents of rank 5 and type $(5,2,1)$ (`SmallGroup(3^8, id)`, ids 1387558–1395381, 7824 groups) through `C39Pass`; none pass, because $P^{*\prime\prime}=1$ for all of them (MATH-127 q3: proved on paper, and checked by `q3.g`). They are **not** all terminal: 190 of the 7824 have a nucleus of order 3 (`q3.g`). `bash run_r5.sh` in a tm job |
| `q3.g`, `run_q3.sh` | MATH-127 q3: for the 7824 groups of type $(5,2,1)$ one CSV line each — $\log_3$ of $Z$, $Z\cap\gamma_2$, $M$, the nucleus $N$, $\gamma_4(P^*)$, $\gamma_5(P^*)$, $P^{*\prime\prime}$, class of $P^*$, $\exp\gamma_2$, $P^3 \le Z$, $\lvert P^3\rvert$; `PqDescendants` of the first `NDESC` non-terminal parents per shard; the family $M_{81}\times 3^{1+2}\times C_3$. Result: 190 non-terminal, all with $\lvert Z\cap\gamma_2\rvert=9$; $P^{*\prime\prime}=\gamma_5(P^*)=1$ everywhere; all descendants metabelian of type $(5,2,1,1)$ |
| `q3e.g`, `run_q3e.sh` | MATH-127 q3: the necessary conditions N1–N3 and the linear system (E) of the wiki page against the nucleus: all 190 non-terminal satisfy them, and so do 573 terminal ones (so (E) is not sufficient) |
| `c39all.g`, `run_c39all.sh` | the full order-$3^9$ run, part $d \le 4$: every `SmallGroup(3^8, id)` of rank 3–4 and class 3–4 as a parent, through `C39Pass` and then `C39One` of `c39.g`, on `NSH` shards (`id mod NSH`); survivors go through a FIFO to `d5z.py` on the fly and are kept gzipped. `bash run_c39all.sh` in a tm job; `EXTRA='IDS:=[..];;'` for a test run |
| `lie_search5.jsonl` | its output: seeds 1–6 × 400 (base), 201–202 × 150 (`wide`), 301–302 × 25 (`212`), $E = 19$; all 2750 rings have $\delta_5 = \gamma_5$ |

The `*.log` files named above are not kept in git (`../.gitignore`); rerunning the scripts writes them.

GAP 4.15 with SmallGroups; Python 3.12 with numpy.
